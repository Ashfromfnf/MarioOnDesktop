# How to un-use!

It's a bit tricky to close it.... unless you use MarioKiller (refer to MarioKiller for more info)

## Windows

1. run MarioKiller-Windows.bat 

2. run `taskkill /F /IM pythonw.exe` in cmd.exe - it does the same thing MarioKiller does - (It ends all tasks running by the pythonw interpreter. The obvious downside being: It closes ALL currently running .pyw files.)

(they do essentially the same)
